# Lucky-Roofing-Company
Lucky Roofing Company is a Whop Website with a deployed storefront and three live Whop plans (a $149 inspection, a $500 deposit, a $225 flat-rate service). It uses Whop Elements checkout with BrandingElement and Apple Pay / Google Pay wallet buttons. The deposit checkout saves the card on file for later off-session charges. The Request an Estimate form creates a member on the Whop account through the Members API, with details added as a note. It uses the Whop Invoices API to bill the final balance by auto-charging the stored card or sending an invoice. whop.track fires estimate_requested, service_viewed and deposit_started, alongside the automatic page-view and checkout events. All business config is in one file for easy rebranding.
